# Audit ikon, simbol, emoji - 15 Oktober 2026

Sumber inspeksi: sembilan PNG asli di EduLMS_UI. Inventaris berikut mencatat kemunculan pada referensi; jumlah aktual mengikuti data.

Koreksi audit: glyph portal kini memakai SVG resmi **Google Material Symbols Outlined**, bukan path outline buatan dengan stroke 1.7. `includes/ui.php` menyisipkan path resmi dengan fill currentColor dan viewBox asli (umumnya 0 -960 960 960). Ukuran visual ditentukan CSS dan atribut width/height; tidak memakai font ikon jarak jauh.

Sumber dan lisensi: [repositori resmi](https://github.com/google/material-design-icons), Apache 2.0. Sebanyak 75 glyph dipatok pada revision 49d4db35df873165d6bd6ba09b063c7dafbac2f4; nama dan URL setiap sumber tersimpan di `assets/vendor/material-symbols/manifest.json`. SVG sumber dan LICENSE disertakan lokal. Contoh yang diidentifikasi: calculate, auto_stories, science, biotech, auto_graph, pending_actions, rate_review, co_present, how_to_reg.

Logo, cover kelas, avatar guru dan enam portrait kecil siswa berasal dari aset fotografi referensi; grid, tulisan, progress, tombol, dan tabel tetap HTML/CSS dinamis. Emoji salam masih glyph sistem; rasterisasi font dan emoji belum identik PNG. Font Awesome dipertahankan pada beberapa kontrol login/detail existing. Tidak ada klaim identik piksel dari kecocokan keluarga glyph saja.
